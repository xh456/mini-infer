# 算力预算计划（总预算 ¥300）

## 价格假设

| 卡型 | 单价 | 说明 |
|---|---|---|
| RTX 4090 (24G) | 约 ¥2.0/小时 | 主力，够跑 0.5B～7B 量化推理 |
| RTX 3090 (24G) | 约 ¥1.2/小时 | 调试开发用，便宜 |
| A100 40G | 约 ¥4-7/小时 | 只在训 1B 模型时短时使用 |

¥300 约等于 150 小时 4090 或 250 小时 3090，但**绝不应该这么花**。

## 分配

| 用途 | 时长 | 费用 | 说明 |
|---|---|---|---|
| P2 引擎基线测量 | 6h | ¥12-15 | 固定环境跑一轮完整对比 |
| P3 吞吐/延迟测量 | 8h | ¥16-20 | 批大小-吞吐曲线 |
| P4 量化实验 | 12h | ¥25-30 | 多组配置，找精度-性能权衡点 |
| P5 预训练 + SFT | 25h | ¥50-60 | 单卡 8-12 小时可完成 100M 模型 |
| P6 端到端评测与消融 | 10h | ¥20-25 | 评测集推理 + judge |
| 返工与意外 | 25h | ¥50-60 | **这部分必须留着，不要提前花掉** |
| 合计 | 约 86h | ¥175-210 | 余量约 ¥90-125 |

## 三条纪律

1. **开发不放云上。** 本地 CPU 与平台免费额度承担 80% 的调试工作量。
2. **测量必须集中成批。** 一次租 4-6 小时，按清单连续跑完，跑完立刻关机。
   零散开机测出来的数据不可比，钱却一分不少花。
3. **每次开机前写清单。** 没有清单就开机，是这份预算最大的敌人。

## 记账方式

每次开机关机后，补一行 `gpu_budget.csv`，累计列用公式自动算。
每周日对一次账：本周花了多少、剩多少、下周该收紧还是可以放开。
